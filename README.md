# Beyond the Page

**Beyond the Page** is a personal digital scrapbook documenting Sofiyah Bakare's six-week journey through the World Literacy Foundation's Youth Power in Action (YAP) programme.

The experience follows her journey through learning, teaching, literacy actions, advocacy, conversations with people around the world, reflections, and what comes next beyond YAP.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Upstash Redis
- Lucide React
- Vercel
